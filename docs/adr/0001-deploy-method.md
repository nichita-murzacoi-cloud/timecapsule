# ADR-0001: Способ доставки кода

**Статус:** принято  
**Дата:** 2026-10-05

## Контекст

Приложение TimeCapsule разворачивается на экземпляре Amazon EC2. Необходимо было выбрать простой и повторяемый способ доставки новой версии приложения на сервер.

## Решение

Для развёртывания используется скрипт `deploy.sh`.

Скрипт выполняет:

- получение новой версии кода из GitHub;
- установку PHP-зависимостей;
- инициализацию базы данных;
- перезагрузку PHP-FPM;
- вывод текущего Git-коммита.

## Рассмотренные альтернативы

### SCP

Позволяет копировать файлы непосредственно на сервер, но неудобен для контроля версий.

### Ручной git pull

Позволяет получать новую версию из GitHub, однако остальные действия приходится выполнять вручную.

### deploy.sh

Объединяет основные действия развёртывания в одну команду и делает процесс повторяемым.

## Последствия

Преимущества:

- простой деплой;
- контроль версий через Git;
- возможность быстрого отката;
- меньше ручных действий.

Недостатки:

- запуск выполняется вручную;
- отсутствует полноценный CI/CD pipeline;
- нет автоматических тестов перед развёртыванием.
