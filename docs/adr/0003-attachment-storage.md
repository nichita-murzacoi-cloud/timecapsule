# ADR-0003: Хранение пользовательских вложений

**Статус:** принято  
**Дата:** 2026-10-18

## Контекст

Приложение TimeCapsule ранее хранило загруженные пользователями файлы на локальном диске EC2.

Такой способ неудобен, потому что файлы зависят от конкретного сервера и могут быть потеряны при замене экземпляра.

## Рассмотренные варианты

- EBS
- EFS
- Amazon S3

## Решение

Для хранения пользовательских вложений выбран Amazon S3.

Приложение получает доступ к S3 через IAM Role.

Для временной выдачи файлов пользователям используются Presigned URL.

## Причины выбора

- файлы не зависят от конкретного EC2;
- поддерживается Versioning;
- можно использовать Lifecycle Rules;
- доступ контролируется через IAM;
- Presigned URL позволяет безопасно открывать приватные объекты.

## Последствия

Преимущества:

- более надёжное хранение;
- удобное масштабирование;
- отсутствие локальной зависимости;
- централизованное хранение файлов.

Недостатки:

- приложение зависит от доступности S3;
- требуется IAM и настройка Bucket Policy.
